# Hedge Calculator

Web version of `hedgecalculator.py`: calculates the best hedge (in terms of average score) for a set of GeoGuessr locations.

Upload a map JSON exported by the community tools (`{"customCoordinates": [{"lat": ..., "lng": ...}, ...]}`), optionally set `MAX_DIST` (default 17502 km) and `n_seeds` (default 100), and the page shows the coordinates of the best hedge, the centroid and the point minimising the sum of distances, along with a map.

Everything runs client-side: `worker.js` is a dependency-free JavaScript port of the pymanopt optimisation (Riemannian conjugate gradient on the sphere, multi-started from `n_seeds` random locations). The basemap uses d3 and Natural Earth 1:50m data from world-atlas, loaded from jsDelivr.

The site also has a **Docs** page (`docs.html`) and an **Examples** page (`examples.html`, with its figures in `examples/`).
`examples.html` is generated by `build_examples.py` (one folder up) from `output.txt`, `outputpruned.txt` and the `figure*.png` files; rerun it after regenerating those.

## Deploying to GitHub Pages

1. Put the contents of this folder (`index.html`, `worker.js`, `style.css`, `docs.html`, `examples.html`, `examples/`) at the root of a repository (e.g. `<username>.github.io`, or any repo).
2. In the repository go to **Settings → Pages**, pick **Deploy from a branch**, choose `main` and `/ (root)`.
3. The site appears at `https://<username>.github.io/` (or `https://<username>.github.io/<repo>/`).

## Running locally

Browsers don't allow Web Workers from `file://` URLs, so serve the folder instead:

```
python -m http.server
```

and open http://localhost:8000.
