What do these maps show?

The purpose of this tool is to find out the best places to hedge in a Geoguessr round. That is, suppose I know the country (from infrastructure clues, language, whatever) and have absolutely zero clue of anything else. Where should I click to maximize my average score?

There are three points given:

"Best Hedge"maximizes your average score on the locations.
"Min sum of dists"minimizes the average distance to the location.
"Centroid"minimizes the average squared-distance to the location.

How are the maps calculated?

I wrote a program in Python which takes a list of locations (e.g., all of the Philippines locs that appear on the map), and returns the coordinates that maximize the average score (the "best" hedge for the Philippines on that map).

The problem is that for most maps, the locations themselves aren't public — oftentimes map makers publish the number of locations per country, but that's it. In that sense the goal is hopeless; for example, if the map maker decided to put a disproportionate number of locations in Mindanao, the optimal guess would be further south, but I would have no way of knowing!

As a proxy, I used a Geoguessr mapmaking tool to generate a couple thousand locations from each country, and used those as an input to the algorithm.

How useful is this really?

This is a pretty small optimization; the change in expected value is not so high that it's likely to make a notable difference in your gameplay.

The maps are the most useful for regions where the Google street view coverage is uneven, so your intuitive "middle click" might not match the actual optimal.

You can also in theory use the program for subdivisions and other metas. If you have a JSON file of locations with, e.g. a particular type of antenna, you can figure out a central place to click when you see it (in the absence of other clues).
